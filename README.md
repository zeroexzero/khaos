## Building

In order to run this project's tests as well as build the project in-game, use greybel-vs.  
If you know what you're doing, this directive doesn't apply to you (but there will be no support).

If you're unsure how to build with Greybel, consider reading their [docs](https://marketplace.visualstudio.com/items?itemName=ayecue.greybel-vs)

The root file for the greybel build is ./src/khaos.src
